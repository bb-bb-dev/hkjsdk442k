Settings guide

SKS AIRSPY Settings

Reference for TubeWitch for SKS AIRSPY settings in Garmin Connect IQ order. Start with units, numeric sensor IDs and pressure targets, then confirm live pressures.

ACTIVE SENSOR SET
  • Active Sensor Set Choose which Sensor Set is shown in the Data Field. Manually select the active set or use Auto Switch to scan each configured set for 10 seconds. If you only have one set, Auto is not recommended.
SENSOR SET #1-5
  • Sensor Set Name Optional. Name the bike or wheelset. The name is also shown in Connect IQ stats.
  • Enabled Sensors Choose Front & Rear, Front Only or Rear Only.
  • Front Sensor ID and Rear Sensor ID Enter the numeric ID printed on each AIRSPY sensor, such as 21760. Place the ID in the slot for the correct wheel. Do not enter a Bluetooth address or BLE device name.
  • Front Low Target / Front High Target Set the low and high pressure limits for the front wheel.
  • Rear Low Target / Rear High Target Set the low and high pressure limits for the rear wheel.

Targets use the selected PSI, bar or kPa unit. A target of 0 is unset and disables that individual comparison. All targets start at 0.

When both targets are set, the high target must be greater than the low target. If it is not, TubeWitch ignores the conflicting high target and keeps the low comparison.

UNIT OF MEASURE
  • Unit of Measure PSI, kPa, or BAR. Garmin reboot recommended after the unit change.
  • Decimal Places Number of digits to the right of the decimal. Forcing extra digits may cause labels to be truncated on small data fields.
  • Show Unit of Measure Show or hide the unit label in the data field.

Extra precision can make small layouts harder to scan. Limit precision to what remains readable while moving. Auto is recommended.

After changing units, update pressure targets in every sensor set. Saved target numbers are not automatically converted; they are interpreted in the newly selected unit.

SENSOR LABELS
  • Show Front/Rear Labels Show or hide front and rear labels in the data field.
  • Show Sensor IDs Show the configured numeric sensor IDs in the data field. A wide field may be needed to see the full ID.
  • Show Sensor Set Name Show the sensor set name in the data field. It may be truncated on small data fields.
  • Horizontal Layout Label Delimiter Choose the separator used on horizontal layouts.

Useful during setup and multi-bike use, but these can crowd very small layouts.

DISPLAY
  • Display Style TubeWitch Mode is the default, but it may be unavailable on some devices that are not yet fully supported. Compatibility Mode uses dynamic font sizing and positioning and works on all devices.
  • Layout Orientation Auto, Vertical, or Horizontal. Horizontal Orientation is not available in narrow fields while using TubeWitch Display Mode.
  • Background Color Auto, Light, or Dark.

TubeWitch Mode is default. Compatibility Mode uses dynamic sizing and positioning for broader device coverage.

Auto, Vertical, or Horizontal layout behavior.

Auto, Light, or Dark styling depending on layout and page contrast.

TOUCH SETTINGS
  • Touch Data Field Enables Touch to Switch Sensor Sets, Touch to Disable TubeWitch, Touch to Rescan after timeout and Touch to Stop Alarm Repeats. Only available on touchscreen devices.
SENSOR TIMEOUT
  • Sensor Timeout Default 15 Minutes. During an activity, TubeWitch times out if no sensors are found. No timeout is applied if an activity is not started.
AUTO SWITCH SCAN DELAY
  • Auto Switch Scan Delay Default 60 Seconds. If both enabled sensors become stale while Active Sensor Set = Auto, TubeWitch waits for this delay before scanning other sets again at 10 seconds each.
HIGH / LOW PRESSURE ALARMS

(Set pressure targets in each Sensor Set in TubeWitch Settings)

TubeWitch calculates low and high status alerts from the received pressure and your configured limits.

Default target values of 0 do not enable pressure-limit alarms.

  • Audible Alert Enable or disable audible pressure alerts on supported Edge Devices and watches.
  • Pop Up Alert Enable popup alerts on newer supported devices.
  • Vibration Alert Enable vibration alerts on supported watches.
  • Alarm Delay Set how many seconds a tire must be high or low before triggering an alarm.
  • Reset Delay Set how many seconds a tire must be within target before resetting the pressure alarm.
  • Alarm Repeat Set the number of additional repeats after the first alarm (90 seconds apart). A value of 0 adds no repeats.
  • Audible Alarm Tone Select the sound used for audible alerts.
  • Data Field Alarm Box Color Choose the box color used for the pressure alarm state. The color change is always active and instantaneous while the condition exists.
ACTIVITY RECORDING

(Garmin reboot required after making recording changes)

  • Record Front Pressure Record front pressure into the activity.
  • Record Rear Pressure Record rear pressure into the activity.
  • Record Front Pressure Alarm Record front pressure alarm status.
  • Record Rear Pressure Alarm Record rear pressure alarm status.
  • Record Front Pressure Stale Data Indicator Record front stale data indicator status.
  • Record Rear Pressure Stale Data Indicator Record rear stale data indicator status.
  • Record Sensor Set # Record the sensor set number used in the activity.

For post-ride review, the most useful additions are often set number and alarm status alongside raw pressure.

Auto Switch Delay Example

After a Garmin Edge power cycle, or after starting a new activity on a watch, Auto Switch will scan each configured sensor set for 10 seconds until it finds one that is active. Keep the sensors moving during setup so they continue broadcasting.

When starting a ride, TubeWitch can lock onto any of the 5 configured sensor sets if they are active and nearby. Once locked on, it will stay on that set until they are out of range and TubeWitch shows "?", indicating that no valid pressure update has arrived within the AIRSPY freshness interval (30 seconds). It then waits for the Auto Switch Scan Delay, default 60 seconds, and resumes scanning all configured sensor sets for 10 seconds each. Sensor broadcast timing affects how long discovery takes. Manually select the set when only one bike or wheelset is in use.

TubeWitch Timeout Examples

If a Garmin activity is started but sensors are not being used, the data field keeps searching until the timeout, default 15 minutes. Then it shows "Sensors Not Found" and stops scanning to save battery. Tapping the Data Field or Stop and Resume can restart the scan.

If a Garmin activity is started and sensors were found but the signals drop, the field shows the last received pressure with a "?" to indicate stale data. If the signal stays missing long enough, the sensor times out after the default 15 minutes. It then shows an "X" next to the pressure, meaning it has stopped searching for that sensor to save battery.

If Auto Switch mode is active and both sensors become stale, TubeWitch starts scanning other configured sensor sets before showing an "X". It will still time out after 15 minutes if no sensors are found.
